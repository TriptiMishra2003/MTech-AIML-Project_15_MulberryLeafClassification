## 1. Dataset Name
Mulberry Leaf Dataset

## 2. Description
This dataset contains images of mulberry leaves belonging to 10 different classes. It is used to develop and evaluate a deep learning model for mulberry leaf classification.

## 3. Dataset Structure
The dataset is organized into two main directories:

- Training set/
- Test set/

Each directory contains subfolders corresponding to the
different mulberry leaf classes.

## 4. Classes
The dataset contains the following 10 classes:

1. ChiangMai60
2. RedKing
3. WhiteKing
4. BlackOodTurkey
5. TaiwanStraberry
6. BlackAustralia
7. Buriram60
8. Kamphaengsaeng42
9. TaiwanMeacho
10. ChiangMaiBuriram60

## 5. Number of Training and Testing data:
Total training images: 3,719 images
Total testing images: 1,543 images
Total images of all classes: 5,262 images

## 6. Number of images in each class are: 
1. ChiangMai60 - 500
2. RedKing - 350
3. WhiteKing - 541
4. BlackOodTurkey - 500
5. TaiwanStraberry - 488
6. BlackAustralia - 637
7. Buriram60 - 345
8. Kamphaengsaeng42 - 500 
9. TaiwanMeacho - 640
10. ChiangMaiBuriram60 - 761

## 7. Preprocessing
The images are resized to 224 × 224 pixels for model input.
Training images are processed using the preprocessing and
augmentation steps defined in the project notebook.
